# Fitness

Workouts, schedules, nutrition, journal, feed, and related user fitness APIs.

- **OpenAPI:** `/openapi/v1/fitness.yaml`
- **Paths:** `/api/v1/workouts/`, `/schedules/`, `/nutrition/`, `/journal/`, `/feed/`, `/users/`
- **Auth:** Bearer (member/fitness user as implemented per route)

Use the filtered OpenAPI file for request/response schemas and operationIds. Prefer that file over scanning the monorepo when wiring a fitness client.
